# Book Recommendation System

## About the Project
The Book Recommendation System is a Java-based project that recommends books based on the user's favorite category.

Users can choose from four categories: Fiction, Mystery, Self-Help, and Science. The system displays recommended books along with their authors and short descriptions.

## Features
- Four different book categories.
- Recommendations based on the user's selected category.
- Displays book names, authors, and descriptions.
- Handles invalid user choices.
- Simple and user-friendly interface.

## Technologies Used
- Java
- Scanner Class
- If-Else Conditional Statements

## Book Categories
1. Fiction
2. Mystery
3. Self-Help
4. Science

## How to Run the Project

### Prerequisites
- Java JDK installed on your computer.
- Visual Studio Code or another Java-compatible editor.

### Steps
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal in the project folder.
4. Compile the Java program:

   javac RecommendationSystem.java

5. Run the program:

   java RecommendationSystem

6. Enter a number from 1 to 4 to select your favorite book category.
